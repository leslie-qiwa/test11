Interactive Quiz Builder for Classroom Use

Overview

This project grew out of a simple frustration: creating engaging quizzes for students was taking far too long with existing tools. I designed and prototyped an interactive quiz builder that lets educators drag question types onto a canvas, customise feedback messages, and export a shareable link in under five minutes.

What It Does

  • Supports multiple question formats: multiple choice, true/false, short answer, and image-based prompts
  • Provides instant feedback to students with customisable explanations for each answer
  • Tracks basic completion data so teachers can identify where students are struggling

What I Learned

Building this taught me as much about instructional design as it did about interface design. Every decision — where to place a button, what language to use in error messages — had a direct impact on whether a teacher would actually use it in their classroom.

Audience

Primary school and secondary school teachers, instructional designers, and ed-tech coordinators.
